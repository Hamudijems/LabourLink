## 2025-05-15 - Enhancing Form Accessibility and Feedback
**Learning:** Adding `autoComplete` attributes to form fields significantly improves the UX for mobile users and those using password managers. Furthermore, providing a clear loading state (like a spinner and text change) on submit buttons prevents double-submissions and gives users confidence that their action is being processed. In Next.js, wrapping components that use `useSearchParams` in a `Suspense` boundary is a critical "micro-UX" for developers as it prevents build-time failures and ensures better client-side hydration.
**Action:** Always include `autoComplete` for standard fields (email, name, tel) and ensure every async button has a loading state. Proactively wrap search-param-dependent components in `Suspense`.
